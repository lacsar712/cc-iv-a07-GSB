# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 铭牌功率专页与对表规则

顶栏点「铭牌功率」进专页：左列填铭牌当量，中列是提交出入口，右列是对表痕迹。

- **估算功率**：开路电压 × 短路电流先折成估算功率（`est_power_w`），再对照该组串的铭牌当量推算填充因子：`推算FF = 估算功率 ÷ 当量`。
- **两条路**：提交时可以交电压电流（按当量推算填充因子），也可以直填填充因子。两条路都交时必须对得上——直填值与推算值偏差超过 ±0.05 即整笔退（422），扫描记录与痕迹都不落账。交电压电流但组串未登记当量，同样拒收（400）。
- **同一次记账**：对表痕迹（`check_traces`）与扫描进队（`iv_scans`）在同一事务落账，要么都成要么都退。
- **观察员**（watcher）能看对表痕迹与当量列表，不能改当量、不能提交扫描（403）。
- 工人口径不变：按落库的填充因子判定，≥ 0.72 合格，否则衰减。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/logs` | 提交扫描：`string_code` 必填，`voc_v`+`isc_a` 与 `fill_factor` 至少一路；两路都交须对得上 |
| GET | `/api/logs` | 扫描记录（含估算功率） |
| GET | `/api/nameplates` | 铭牌当量列表（登录即可） |
| POST | `/api/nameplates` | 登记/更新当量（仅扫描员）：`string_code`、`rating_w` |
| GET | `/api/traces` | 对表痕迹（登录即可，观察员可看） |

## 种子

| 组串 | 铭牌当量 | 填充因子 | 结论 |
|------|----------|----------|------|
| 阵列A-串03 | 480 W | 0.78 | 合格 |
| 阵列B-串11 | 520 W | 0.61 | 衰减 |

以阵列A-串03为例：送 Voc 41.2、Isc 9.1，估算功率 374.92 W，推算 FF = 374.92 ÷ 480 ≈ 0.781 → 合格；故意送 Voc 38.0、Isc 8.4，推算 FF = 319.2 ÷ 480 ≈ 0.665 → 衰减。
