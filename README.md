# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

顶栏可切到**铭牌功率专页**：开路电压 × 短路电流先折成估算功率（保留两位）、取整成当量（W），再拿当量跟对照表查标准填充因子。当量可以由电压电流折算，也可以在左侧直接手填；填充因子也可直填作为第二条路。两条路都交时必须对得上（直填 FF 与表内标准值误差 ≤ 0.02），对不上或对照表无此档，整笔退回、什么都不写。每次成功提交都在右栏留下**对表痕迹**，痕迹与扫描进队（含 NOTIFY 唤醒）是同一事务——成则一起成、败则一起回滚。观察员 watcher 能看对照表与痕迹，但表单禁用、提交返回 403。


## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 种子

| 组串 | 电压×电流→估算功率→当量 | 填充因子 | 结论 |
|------|------|----------|------|
| 阵列A-串03 | 41.2V×9.1A = 374.92W → 375W | 0.78 | 合格 |
| 阵列B-串11 | 38.0V×8.4A = 319.20W → 319W | 0.61 | 衰减 |

对照表初始两档：**375W → 0.78（合格）**、**319W → 0.61（衰减）**。两条种子组串均带对表痕迹。

## 铭牌专页接口（均需登录）

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/nameplate/lookup` | 扫描员/观察员 | 对照表（当量→标准FF） |
| GET | `/api/nameplate/traces` | 扫描员/观察员 | 对表痕迹（只读） |
| POST | `/api/nameplate/submit` | 仅扫描员 | 左填 `power_equiv_w` 或交 `voc_v`+`isc_a`，可选 `fill_factor`；对不上整笔 400 退回 |
